# TINO Documentation

TINO is a terminal-based, Chrome-Dino-style endless runner, run via the `tino` command on macOS and Linux (Bash and Zsh).

This folder is the single source of truth for what TINO is, how it's built, and why. Read in order if you're new to the project.
